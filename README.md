
# PRINCE OF SHADOWS 2D

Videojuego de plataformas 2D desarrollado
con Python y Pygame.

## Descripcion

El jugador debe superar tres niveles,
recolectar monedas, evitar trampas y
llegar a la puerta final.

## Caracteristicas

- 3 niveles independientes
- Movimiento y salto
- Sistema de gravedad y colisiones
- Monedas y puntuacion
- Trampas y vidas
- Cronometro
- Menu principal
- Pantalla de pausa
- Game Over
- Pantalla de victoria

## Tecnologias

- Python
- Pygame
- Git
- GitHub

## Instalacion

Instalar las dependencias:

    python -m pip install -r requirements.txt

Ejecutar el videojuego:

    python main.py

## Controles

- A / D: mover al personaje
- Flechas: movimiento
- Espacio: saltar
- P: pausar
- ESC: volver al menu

## Estructura

- main.py: programa principal
- player.py: fisicas del personaje
- graphics.py: graficos
- settings.py: configuracion
- levels/: niveles independientes
- ui/: interfaz
